# Lecture 02 Task 1

Wokwi project link: https://wokwi.com/projects/478037977771650049

![circuit](circuit.png)

This project reads the NTC sensor using analogRead() and calculates the temperature using the Steinhart–Hart equation.  
If the temperature exceeds the threshold of 30°C, the red LED blinks; otherwise, the green LED stays on.
